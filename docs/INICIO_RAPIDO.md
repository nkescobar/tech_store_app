# ⚡ **INICIO RÁPIDO - TechStore**

## 🚀 **3 Pasos para Ejecutar la App**

### **1️⃣ Instalar PHP**
```bash
# macOS
brew install php

# Windows (como Administrador)
choco install php

# Linux
sudo apt install php php-sqlite3
```

### **2️⃣ Descargar Proyecto**
```bash
git clone https://github.com/nkescobar/tech_store_app.git
cd tech_store_app
```

### **3️⃣ Ejecutar**

#### **Windows:**
```bash
# Doble clic en:
INSTALL_WINDOWS.bat

# O en terminal:
php -S localhost:8000
```

#### **macOS/Linux:**
```bash
# Ejecutar script:
./install_mac.sh

# O directamente:
php -S localhost:8000
```

## 🌐 **Acceder**
Abrir navegador en: **http://localhost:8000**

## ✅ **Verificar**
- ✅ Página carga con productos
- ✅ Botones editar/eliminar funcionan
- ✅ Formulario agregar funciona

## 📊 **Base de Datos**
**🚨 IMPORTANTE:** Este proyecto usa **MySQL** como base de datos principal para el taller. SQLite se usa automáticamente solo para desarrollo local cuando MySQL no está disponible.
